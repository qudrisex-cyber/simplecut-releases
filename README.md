# SimpleCut for Windows

Простой инструмент для нарезки видео по таймкодам и сохранения кадров в PNG/JPG. Windows 10/11, x64.

## Обновление до 0.4.2

**Обновления → Проверить обновления → Скачать обновление.** Сначала сохрани нужные файлы, затем полностью закрой SimpleCut и запусти снова. Несохранённые отрезки после перезапуска не восстанавливаются.

Пакет обновления: **26 892 байт (около 26 КБ)**. Переустановка Python, Qt и FFmpeg не требуется. Аккаунт GitHub для скачивания не нужен.

## Что нового

В 0.4.2: Alt+S сохраняет фото в последнюю папку, при первом использовании папка выбирается один раз. Имена создаются автоматически без перезаписи существующих фото. После записи появляется «Фото сохранено» и «Показать в папке». Движение мыши после клика больше не перематывает видео. Колесо над шкалой изменяет масштаб вокруг курсора, полоса прокрутки перемещает увеличенный участок, «Показать всё» сбрасывает масштаб. Клик выбирает кадр на паузе. Проверен переход с опубликованного EXE 0.4.1.

В 0.4.1 добавлена тонкая скруглённая рамка списка, увеличены иконки и подписи кнопок, выровнены их границы. Проверена установка небольшого пакета в опубликованный EXE 0.4.0.

- Чёрный интерфейс с объёмными панелями, красными акцентами и векторными иконками.
- Нажми «Отрезок» во время просмотра: начало будет в текущей позиции. Продолжай смотреть и нажми «Конец». Кнопка «Начало» меняет начало выбранного отрезка.
- Выбирай строку для редактирования названия и времени. Цветные диапазоны на шкале соответствуют строкам. Щелчок по диапазону выбирает отрезок и перемещает просмотр.
- Отрезки без конца остаются черновиками и исключаются из общего сохранения. Неверные заполненные таймкоды требуют исправления.
- Покадровый просмотр и фоновое сохранение фото в полном разрешении сохранены. Шкала пока без миниатюр.

Кеш уменьшенных кадров ограничен 128 МиБ; это не лимит всей памяти приложения и декодера. Кеш очищается при перемотке, воспроизведении, замене исходника и закрытии. Первый шаг после перемотки может требовать ожидания.

## Если установлена сломанная 0.3.0

В 0.3.0 кнопки обновления ломались из-за конфликта сигнала Qt. Для восстановления:

1. Закрой SimpleCut.
2. Скачай [application.zip из 0.3.1](https://github.com/qudrisex-cyber/simplecut-releases/releases/download/v0.3.1/application.zip), не распаковывай.
3. Через Win + R открой `%LOCALAPPDATA%\Programs\SimpleCut` либо свою папку установки.
4. Переименуй старый application.zip в application-0.3.0-backup.zip, скопируй скачанный application.zip рядом с SimpleCut.exe.
5. Запусти приложение и обновись через кнопку «Обновления».

Полную основу для этого скачивать заново не нужно.

## Проверки и ограничения

Windows-проверки 0.4.0 прошли: экспорт и отмена, фото и покадровый просмотр, кеш и завершение декодера, замена исходника, активные отрезки и черновики, реальные кнопки обновления и откат. Опубликованный установщик 0.3.6 принимает небольшой пакет, его существующий EXE запускает 0.4.0 и сохраняет версию при втором запуске. Проверена совместимость и с EXE 0.3.0.

Автоматические UI-проверки подставляют ответы нативных диалогов. Физический дисплей, аудиоустройство, реальное масштабирование Windows и ручное перетаскивание из Проводника ими не подтверждаются.

Установщик пока без цифровой подписи. SHA256SUMS.txt содержит контрольные суммы. Пакеты содержат читаемый код приложения. Обновление Python, Qt, FFmpeg или механизма запуска требует полного установщика.
