# SimpleCut for Windows

Простой инструмент для нарезки видео по таймкодам. Windows 10/11, x64.

## Исправление для установленной 0.3.0

В 0.3.0 кнопки проверки обновления и установки файла ломались из-за конфликта сигнала Qt. Это исправлено в **0.3.1**.

1. Закройте SimpleCut.
2. Скачайте [application.zip из 0.3.1](https://github.com/qudrisex-cyber/simplecut-releases/releases/download/v0.3.1/application.zip). Не распаковывайте.
3. Нажмите Win + R и откройте `%LOCALAPPDATA%\Programs\SimpleCut` (или свою папку установки).
4. Переименуйте старый application.zip в application-0.3.0-backup.zip, затем скопируйте скачанный application.zip рядом с SimpleCut.exe.
5. Запустите программу: версия должна быть **0.3.1**. Проверьте кнопку обновлений.

Пакет занимает около 16 КБ. Это те же байты, что и версионный пакет SimpleCut-0.3.1-update.zip. Полную основу заново скачивать не требуется.

## Следующие обновления

После исправления: **Обновления → Проверить обновления → Скачать обновление**. Сохраните нужные отрезки, закройте и снова откройте приложение. Несохранённые карточки пока не восстанавливаются.

Сейчас последняя версия — **0.3.1**. После её установки проверка сообщит, что версия актуальна. Будущие размеры пакетов зависят от изменений; обновление Python, Qt, FFmpeg или механизма обновления требует полного установщика.

Аккаунт GitHub для скачивания файлов не нужен. Пакеты содержат читаемый код приложения. Установщик пока без цифровой подписи.

## Проверки

В 0.3.1 добавлены тесты действий в окне обновлений: проверка и скачивание кнопками, завершение потока, установка файла, отмена и отказ, ошибка сети и повторная попытка, восстановление управления после ошибки запуска задачи, прогресс и закрытие во время работы. Новый тест также отклоняет выпущенный сломанный код 0.3.0.

Новый пакет проверяется с выпущенным EXE 0.3.0, включая реальные запросы к публичному каналу из окна обновлений. Автоматические ответы системного выбора файла и подтверждения подставляются. Физический дисплей, звук и ручное взаимодействие с Проводником не покрываются этими проверками.

Публичная проверка дополнительно скачивает реальные опубликованные файлы без авторизации, сверяет суммы, устанавливает программу и активирует пакет в одноразовой тестовой установке. Для этой проверки понижается только версия тестовой основы; опубликованные файлы не изменяются.
