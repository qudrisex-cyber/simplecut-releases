# SimpleCut for Windows

Простой инструмент для нарезки видео по таймкодам.

## Скачать

Установщики и небольшие пакеты обновлений публикуются в разделе **Releases**.
Для первой установки или перехода с 0.2.x нужен полный установщик. Пакеты `*-update.zip` предназначены для приложения с поддержкой небольших обновлений (0.3.0+).

В программе: **Обновления → Проверить обновления → Скачать обновление**. После загрузки сохраните нужные отрезки и перезапустите SimpleCut. Несохранённые карточки пока не восстанавливаются.

Этот репозиторий используется для публичной раздачи файлов. Пакеты обновлений содержат код приложения. Отдельный сервер и аккаунт GitHub для скачивания опубликованных файлов не нужны.

Windows 10/11, x64. Установщик пока без цифровой подписи.
