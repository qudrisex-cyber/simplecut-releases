# SimpleCut for Windows

Простой инструмент для нарезки видео по таймкодам.

## Скачать

[Установщик SimpleCut 0.3.0 для Windows x64](https://github.com/qudrisex-cyber/simplecut-releases/releases/download/v0.3.0/SimpleCut-0.3.0-Setup.exe) — около 65 МБ.

[Все выпуски и файлы](https://github.com/qudrisex-cyber/simplecut-releases/releases).

Для первой установки или перехода с 0.2.x нужен полный установщик. Python отдельно не требуется. После установки запускайте SimpleCut ярлыком в меню «Пуск» или на рабочем столе.

## Обновления

В программе: **Обновления → Проверить обновления → Скачать обновление**. После загрузки сохраните нужные отрезки, закройте и снова откройте SimpleCut. Несохранённые карточки пока не восстанавливаются.

Сейчас последняя версия — **0.3.0**. Сразу после её установки проверка сообщит, что установлена актуальная версия. Следующие обновления появятся после публикации новых выпусков.

Обычные изменения кода доставляются отдельным ZIP-пакетом; пакет 0.3.0 занимает 15 605 байт. Размер будущих пакетов зависит от изменений. Обновление Python, Qt, FFmpeg или самого механизма обновления требует полного установщика.

Пакеты `*-update.zip` предназначены для приложения с поддержкой небольших обновлений (0.3.0+). Не нужно устанавливать пакет поверх такой же версии.

Этот репозиторий используется для публичной раздачи файлов и проверки релизов. Пакеты содержат код приложения. Аккаунт GitHub для скачивания опубликованных файлов не нужен.

Проверено: скачивание без авторизации, контрольные суммы, установка в Windows, активация скачанного пакета в тестовой установке, повторный запуск и реальный экспорт FFmpeg. Для проверки активации только в одноразовой тестовой установке понижается версия основы; опубликованные файлы не изменяются. Проверки интерфейса выполняются без физического дисплея и аудиоустройства.

Windows 10/11, x64. Установщик пока без цифровой подписи.
